Файл — выгрузка «Ведомость по товарам» из 1С с иерархией Номенклатура → Склад → Документ движения.

  • Берутся только документы Расходная накладная и Корректировка реализации.
  • Товар сопоставляется по Номенклатура.Код; если товара нет в каталоге, запись всё равно сохраняется (по коду).
  • Склады сопоставляются: Оптовый Кемерово (АМС) → Кемерово, Новокузнецк (АМС) → Новокузнецк, Склад Новосибирск (АМС) → Новосибирск. Транзитные склады пропускаются.
  • Повторная загрузка обновляет записи (по складу, коду и документу), а не дублирует их.
