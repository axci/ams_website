Header row columns (case-insensitive): sku, article, Name, category, subcategory, model product, weight, weight_m (ед. изм. веса, напр. кг/г), volume, volume_m (ед. изм. объёма, напр. л/мл), viscosity (вязкость), manufacturer number, price.

Products are matched and created by sku (existing products are updated). Categories, subcategories, models and brands are matched case-insensitively and created if missing.

Any other column (for example a city name such as Новосибирск) is treated as a warehouse, and its cells as the stock quantity for that warehouse (the warehouse is created if it doesn't exist).
